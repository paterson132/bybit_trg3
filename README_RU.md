# Bybit SMA Bot 2.3

Версия 2.3 исправляет частые повторные запросы свечей: после первичной загрузки истории бот запрашивает свечи только после закрытия следующей свечи выбранного таймфрейма. Обновление веб-панели обращается только к локальному `/api/status` и не создаёт запросов свечей к Bybit.

## Запуск в Windows

1. Установите Python 3.11+.
2. Распакуйте архив в отдельную папку.
3. Запустите `run_windows.bat` или откройте CMD в папке проекта и выполните:

```bat
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

4. Откройте http://127.0.0.1:8000.
5. Используйте деморежим и демо API-ключи до завершения проверки.

## Изменения 2.3

- Один фоновый рабочий поток; повторный запуск второго потока блокируется.
- Первичная загрузка истории выполняется один раз при старте, чтобы прогреть SMA(20)/SMA(80); старая свеча при запуске не используется для открытия сделки.
- Дальнейшие запросы свечей планируются на границу выбранного таймфрейма плюс 1 секунда: 1m, 3m, 5m, 15m, 30m, 45m, 1h, 2h, 4h, 1d.
- 45-минутные свечи собираются из трёх 15-минутных свечей; запрос выполняется по расписанию 45m, а не каждые 15 минут.
- Свечи фильтруются по времени закрытия; текущая незакрытая свеча не участвует в расчёте SMA и сигнале.
- UI показывает цену последней обработанной закрытой свечи, время этой свечи и приблизительное время следующей проверки. Обновление статуса в браузере не вызывает запросы к Bybit.
- При ошибке API, включая лимит `10006`, бот не начинает быстрый цикл повторов: следующая попытка — на следующем закрытии свечи.
- Сигнал разрешён только при переходе в целевую направленную зону, что предотвращает повторный вход по каждой следующей свече той же зоны.
- Перед входом проверяется позиция на бирже; цена SL/TP округляется по шагу инструмента. Если Bybit отклоняет SL/TP после рыночного входа, бот пытается отправить reduce-only закрытие и записывает критическое сообщение в журнал.

## Важные ограничения

- Это программная версия для тестирования, не гарантия безошибочной торговли. Проверяйте все действия на демо-аккаунте, включая SL/TP, ошибки сети, частичное исполнение и восстановление после перезапуска.
- Состояние стратегии в памяти сбрасывается при перезапуске. При старте бот прогревает индикаторы и не торгует по старому сигналу, но следует вручную проверить открытую позицию и защитные ордера на бирже.
- Цена в панели — цена закрытия последней обработанной свечи, а не потоковая цена в реальном времени.
- Для таймфрейма 45m данные агрегируются из 15m. Если история содержит пропуски, неполные 45m-группы исключаются.
- API-ключ не должен иметь права вывода средств. Не публикуйте сервер в интернете. Интерфейс привязан к `127.0.0.1`.
- Настройки по умолчанию — маржа 15% баланса и плечо 50x; это крайне рискованно и может привести к быстрой ликвидации. Сначала используйте деморежим и меньшие значения.
