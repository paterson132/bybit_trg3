Внимание: высокий риск

15% баланса здесь считается маржой. При плече 50× номинал позиции может составить около 7,5× всего баланса. Начните с демо. API-ключи вводятся в локальный сервер и хранятся только в памяти процесса; не публикуйте этот сервер в интернете. Не включайте вывод средств в правах API.

1. Подключение

Для демо создайте API-ключ именно в демо-среде Bybit. Для реальной торговли используйте отдельный ключ без права вывода.

2. Настройки стратегии

Бот загружает историю при запуске, затем делает один запрос свечей после каждого закрытия выбранного таймфрейма. Таймфрейм 45 минут собирается из трёх закрытых 15-минутных свечей.

3. Управление

Остановка бота прекращает новые входы, но не закрывает уже открытую позицию. SL/TP выставляются на стороне биржи после входа.

Текущее состояние

Цена обновляется после закрытия свечи; обновление страницы не вызывает запросов свечей к Bybit.
